# Triage Labels

Map the five canonical triage roles to this repository’s issue labels:

- `needs-triage` → `needs-triage`: maintainer evaluation needed.
- `needs-info` → `needs-info`: waiting for information from the reporter.
- `ready-for-agent` → `ready-for-planning`: fully specified, ready for an autonomous agent.
- `ready-for-human` → `ready-for-human`: requires human implementation.
- `wontfix` → `wontfix`: will not be actioned.

When a skill mentions a canonical role, use the corresponding tracker label. The mapping changes label names, not the roles’ meanings.
